# OpenFOAM plane-Couette anchor for the L3 bridge

Generated by `scripts/openfoam_couette_anchor.py`. OpenFOAM v2606 in WSL, `simpleFoam`, laminar, gap H = 0.001 m, 20 cells, rho = 1060 kg/m^3, 8 wall speeds per record.

The comparison uses OpenFOAM's own `nu` field and its `wallShearStress` function object against `record.eta_at`. It does not touch `biorheo.solver.openfoam.nu_openfoam`, so it is an anchor on the transcription of `calcNu`, not a restatement of it.

Worst defined value here: 0.00437. The residual is not a criterion at all: its worst final value is 1.660e-15.

## Every case

`wall imbal` is |tau_upper + tau_lower| / mean|tau| on the SIGNED x-tractions: in steady plane Couette the two walls carry equal and opposite traction, so it is a consistency check needing NO reference value -- the one diagnostic here that a user with no analytic answer could still run. `clamp early/final` is the fraction of cells sitting on the viscosity cap at the first window and at the end: setting `eta_max` 10x clear of the converged viscosity says nothing about the transient, and the transient is where the low-rate case spends its whole budget.

## The finding the first run produced (kept, because it is the product point)

An identified record exported to OpenFOAM is not automatically usable in OpenFOAM. On this trivial 20-cell 1-D problem the convergence rate of `simpleFoam`'s outer iteration is set by the local Bingham number `B = tau_y/(k gd^n)`, and the failure is SILENT: `rc = 0`, no warning, a written result.

Measured on `carbopol_etd2020_0p1wt_30uL` (tau_y = 2.602 Pa, k = 4.918 Pa s^n, n = 0.579) by `scripts/openfoam_couette_diagnose.py`, with `residualControl 1e-12` restored so 'did it meet the criterion' is measurable.

Read three things off it. (1) At B = 28.9 with relaxation 0.3 and a 2000-iteration budget the solver returns a viscosity 900 % wrong with no error. (2) Under-relaxing HARDER makes it worse: relaxation 0.3 is 3.05e+11x worse than 0.95 at the same 20000-iteration cap -- the usual reflex is the wrong one here. But there are TWO regimes, not one mechanism: below the shipped setting the outer loop is a slowly damped relaxation (small factor, many iterations), while at relaxation 0.99 it is genuinely unstable -- simpleFoam dies with SIGFPE after the continuity error blows up. The working 0.95 sits between a slow regime and an unstable one, which is a narrow place to be and is stated rather than hidden. (3) The normalised residual is not a usable stopping criterion here: only the B = 2.01 case ever meets 1e-12, while the answer improves by many decades past the point where the residual stops moving. That is why A5' is a Cauchy test on the field.

The practical consequence for the bridge: the low-rate end of a yield-stress record is where a solver hand-off goes wrong, and it is exactly the end a rheometer measures worst. `export_report`'s `cap_binds` flag does not catch it -- the clamp was 10x clear of the envelope in every row above.

### A detector that needs no reference answer

Every gate above compares against `record.eta_at`, which a real case does not have. The one quantity here that does not is the WALL TRACTION IMBALANCE |tau_upper + tau_lower| / mean|tau|: the momentum balance that makes tau uniform requires the two walls to carry equal and opposite traction, so any departure is self-evident error. Over the 11 diagnosis cases, spanning 1.18e+14x in the true error, its Spearman rank correlation with the true `nu` error is 0.9818, and it runs 0.00899 to 0.385 times that error -- i.e. it is a conservative flag, one to two decades BELOW the error it is signalling, not a calibrated estimate of it. Used as `imbalance >> round-off`, it would have caught every bad case in this study.

### Is it really B, or just the viscosity? (the confound, tested)

The rate sweep above moves B, the viscosity eta and the wall speed U0 together, so on its own it cannot attribute anything to B. This 2x2 fixes gd = 0.01 1/s (hence U0, the mesh and the boundary conditions) and picks synthetic Herschel-Bulkley parameters that hit a target (B, eta) pair: at fixed gd, `k gd^n = eta gd/(1+B)` and `tau_y = B eta gd/(1+B)`, so scaling tau_y and k by a common factor moves eta at constant B. The verdict rule (a 10x separation) was fixed before the run.

| B | eta (Pa s) | tau_y (Pa) | k (Pa s^n) | nu rel err |
|---|---|---|---|---|
| 2 | 0.5 | 0.00333333 | 0.02398 | 3.0791e-05 |
| 2 | 50 | 0.333333 | 2.398 | 3.0791e-05 |
| 29 | 0.5 | 0.00483333 | 0.002398 | 1.7373e+00 |
| 29 | 50 | 0.483333 | 0.2398 | 1.7373e+00 |

Across B at fixed eta the error moves 5.642e+04x at eta = 0.5, 5.642e+04x at eta = 50.0; across a 100x change in eta at fixed B it moves 1x at B = 2.0, 1x at B = 29.0. **Verdict: B controls.** The two eta rows agree to the digits printed, which is what a genuine invariance looks like -- the solve is unchanged by a common rescaling of (tau_y, k), so it is the yield-to-viscous RATIO that sets the convergence, not the size of the viscosity, the wall speed or the matrix conditioning.
