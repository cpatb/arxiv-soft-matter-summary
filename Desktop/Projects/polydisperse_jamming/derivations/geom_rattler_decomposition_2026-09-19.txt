1. THE DECOMPOSITION IS AN IDENTITY, NOT A MODEL -- SymPy check
==============================================================================
   phi        = (V_B + V_R)/V
   phi_B      = V_B/V
   psi        = V_R/(V_B + V_R)
   phi - phi_B/(1-psi) simplifies to: 0
   -> phi = phi_B/(1-psi) is an IDENTITY.  [asserted zero]

   Which PSD moment enters. With N grains, rattler set R, |R| = qN:
       psi = sum_{i in R} d_i^3 / sum_i d_i^3 = q * <d^3>_R / <d^3>
   so the functional of the PSD that the depopulation picture needs is the
   THIRD moment CONDITIONED ON THE RATTLER SET, not <d^3>, not d32, not d43.
   At CV = 0 every grain has the same d, so <d^3>_R = <d^3> and psi = q
   EXACTLY.  That makes the monodisperse cell a zero-width anchor.

   Bound (rearrangement inequality).  For fixed q, sum_{i in R} d_i^3 is
   minimised by taking the q smallest grains and maximised by the q largest:
       Psi(q) <= psi <= 1 - Psi(1-q),   Psi(q) = int_0^{F^-1(q)} d^3 f dd/<d^3>
   Psi is closed form per family (geom_common_20260919.Psi).

   Closed forms, derived not asserted:
     lognormal  d = exp(mu + sigma Z):  E[d^3 1(Z<z)] = E[d^3] Phi(z - 3 sigma)
                so Psi(q) = Phi(Phi^-1(q) - 3 sigma),  sigma^2 = ln(1+CV^2)
     uniform    Psi(q) =  (-t**4 + (w - 1)**4)/((w - 1)**4 - (w + 1)**4)  with t = 1-w+2wq, w=CV*sqrt3
     bidisperse small-grain volume share w_s = (c - 1)**3/((c - 1)**3 - (c + 1)**3)
                Psi(q) = 2 q w_s               (q <= 1/2)
                Psi(q) = w_s + (2q-1)(1 - w_s) (q >  1/2)

==============================================================================
5b. SIZE SELECTIVITY -- where the required rattler set sits between the two extreme models
==============================================================================
   Two limiting models for WHICH grains rattle:
     S = 1  'size-ordered':  the rattlers are exactly the q smallest grains,
            which is what a pure coordination threshold z(d) < 2 gives, since
            the expected neighbour count of a grain grows monotonically with d
            -> psi = Psi(q).
     S = 0  'size-blind':    rattling is independent of size -> psi = q.
   Define  S = (q - psi_req)/(q - Psi(q)),  so S in [0,1] interpolates and an
   S outside [0,1] REFUTES H1 (S > 1 is section 3's refutation).

   CAN decide:  whether H1 is impossible, i.e. whether ANY assignment of
