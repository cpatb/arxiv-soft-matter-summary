1. WHAT 'SEPARABLE' MEANS, AND THE ONE STATISTIC THAT TESTS BOTH FORMS
==============================================================================
   ADDITIVE       phi(c,m) = F(c) + G(m)
   MULTIPLICATIVE phi(c,m) = F(c) * G(m)

   The seed-paired CV increment D(c,m) = phi(c,m) - phi(0,m):
     additive:       D = -F(0) + F(c)   -- free of m
     multiplicative: D = (-F(0) + F(c))*G(m)   -- proportional to G(m) = phi(0,m)/F(0)

   So ONE statistic decides between them.  Write r_m = phi(0,m1)/phi(0,m0).
     additive       predicts  D(c,m1) - D(c,m0) = 0
     multiplicative predicts  D(c,m1) - D(c,m0) = (r_m - 1) D(c,m0)
   Both are parameter-free once phi(0,m) is measured, and their SEPARATION is
   |r_m - 1| * D(c,m0), which is printed below beside the residual so the test
   can declare itself uninformative.

   General transform.  If phi separates additively after a smooth monotone
   h, i.e. h(phi) = F(c) + G(m), then to first order in D
     h(phi(c,m)) - h(phi(0,m)) = h'(phi(0,m)) D(c,m) + O(D^2) = F(c) - F(0)
   so   D(c,m1)/D(c,m0) = h'(phi(0,m0))/h'(phi(0,m1))   for EVERY c.
   That ratio is a single number fixed by h, so the CV-dependence of the
   measured ratio is a transform-free test: **no monotone h whatsoever can
   separate the data if D(c,m1)/D(c,m0) depends on c.**
   h = identity  -> ratio 1 (additive)
   h = log       -> ratio phi(0,m1)/phi(0,m0) (multiplicative)
   h = 1/phi (specific volume) or h = (1-phi)/phi (void ratio)
                 -> ratio (phi(0,m1)/phi(0,m0))^2
   h = phi^k     -> ratio (phi(0,m1)/phi(0,m0))^(k-1)
     SymPy: h = phi^k        -> h'(phi_0)/h'(phi_1) = phi_0**(k - 1)*phi_1**(1 - k)
     SymPy: h = log phi      -> h'(phi_0)/h'(phi_1) = phi_1/phi_0
     SymPy: h = 1/phi        -> h'(phi_0)/h'(phi_1) = phi_1**2/phi_0**2
     SymPy: h = (1-phi)/phi  -> h'(phi_0)/h'(phi_1) = phi_1**2/phi_0**2

   The depopulation picture (geom_rattler_decomposition) writes
       phi_J(CV,mu) = phi_B(mu) / (1 - psi(CV,mu)).
   If psi depended on CV ALONE this would be EXACTLY MULTIPLICATIVE.
   Section 3 refutes multiplicative.  So psi must be friction-dependent, and
