1. THE ISOSTATIC COUNT, DERIVED -- and it contains no length
==============================================================================
   Count STATIC DETERMINACY: the contact forces are determined by balance
   alone exactly when the number of independent unknowns equals the number of
   independent equations.

   EQUATIONS.  Each rigid grain gives d force-balance and d(d-1)/2
   torque-balance equations:  d + d(d-1)/2 = d(d+1)/2 per grain.
     total equations = N*d*(d + 1)/2  -> at d = 3: 6*N

   UNKNOWNS.  Each contact carries d force components (1 normal, d-1
   tangential).  At a FULLY MOBILISED contact the tangential magnitude is
   pinned to mu f_n, which removes one unknown.  With x_m the mobilised
   fraction:
     total unknowns = N_c*(d - x_m)  = N_c (d - x_m)

   Setting them equal and using z = 2 N_c / N:
     z_iso = d*(d + 1)/(d - x_m)   = d(d+1)/(d - x_m)
     at d = 3:  z_iso = -12/(x_m - 3)  = 12/(3 - x_m)

   LIMITS (asserted):
     x_m = 0 (nothing sliding, friction fully effective): z_iso = 4 = d + 1
     x_m = 1 (every contact sliding, i.e. mu -> 0):       z_iso = 6 = 2d
     2D check: d(d+1)/(d-x_m) at d = 2 gives 3 at x_m=0 (=d+1=3) and 6 at x_m=1 (=2d=4).  OK

   External anchor (API-resolved, given in the brief): van Hecke, J. Phys.:
   Condens. Matter 22, 033101 (2010), doi:10.1088/0953-8984/22/3/033101,
   states d+1 <= z_c <= 2d for frictional spheres with z_c DECREASING in mu.
   The derivation above reproduces both bounds and supplies the interpolant:
   larger mu means fewer contacts sit at the Coulomb cone, so x_m falls and
   z_iso falls -- the decreasing trend is a consequence, not an assumption.

   THE POINT FOR THIS PROJECT.  Every symbol above is a COUNT.  Grain
   diameters appear nowhere, so:
     PREDICTION P1: z_iso is independent of the size distribution at fixed mu.
   This is the sense in which 'the backbone does not restructure' is not a
   coincidence -- it is forced, PROVIDED the pack is marginally rigid and
   x_m does not itself depend on CV.  The second proviso is the whole item.
