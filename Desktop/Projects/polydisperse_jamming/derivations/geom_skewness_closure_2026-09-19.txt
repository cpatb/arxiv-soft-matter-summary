0. SETTLING c2 = 0.0857 vs 0.857 HERE, not by trusting a lookup
==============================================================================
   Two independent literature passes on 2026-09-19 came back with DIFFERENT
   values of c2 from the same paper: 0.0857 (reported as the PUBLISHED PRE
   value) and 0.857 (which is what arXiv:1303.4627v2 prints, in both the
   Fig. 2 caption and the body).  A factor of ten in the skewness term is
   not something to resolve by which agent spoke last, so it is settled
   here by arithmetic on quantities the paper states in words.

   (a) D&W's own worked example, quoted in their results section:
       'for delta = 0.40 and S = 0, phi_RCP is shifted upward by ~0.02.
        Fixing that value of delta, changing S to +-1 shifts phi_RCP by
        ~+-0.02.'
       delta term  c1 * 0.40                  = 0.02632  vs '~0.02'
       skew term   c2 * 1 * 0.40^2, c2=0.0857  = 0.01371  vs '~0.02'  -> CONSISTENT
       skew term   c2 * 1 * 0.40^2, c2=0.857   = 0.13712  vs '~0.02'  -> OFF BY 7x

   (b) Admissibility.  phi_RCP cannot exceed the FCC limit pi/(3 sqrt 2) =
       0.740480.  Evaluate Eq. (4) at their own largest
       posted |S| = 2.50 and largest delta = 0.413:
       c2=0.0857  -> phi_RCP = 0.69772   admissible
       c2=0.857   -> phi_RCP = 1.02662   IMPOSSIBLE (above FCC)

   (c) This project's own data, section 5 below: at the matched-binary pair
       (delta = 0.5, S = 8/3) the two values predict a gap of
       c2=0.0857  -> +0.05713   against a measured +0.0635 +- 0.0032
       c2=0.857   -> +0.57133   against a measured +0.0635 +- 0.0032

   All three agree: c2 = 0.0857.  Used throughout.  Anyone citing the
   PREPRINT for this coefficient gets the skewness term ten times too large.

3. IS THE FAMILY EFFECT A SKEWNESS EFFECT?  -- the discriminating half
==============================================================================
   A closure that returns the same number for both families would 'agree'
   with neither family's shape, so the informative statistic is the RATIO
   lognormal/uniform, which in D&W is set ENTIRELY by the c2 S delta^2 term
   (uniform has S = 0 exactly).
     CV = 0.3:  D&W ratio 1.362   measured ratio 1.296 +- 0.070   t = -0.94  -> agree
     CV = 0.4:  D&W ratio 1.659   measured ratio 1.715 +- 0.044   t = +1.30  -> agree
     CV = 0.5:  D&W ratio 2.058   measured ratio 2.433 +- 0.200   t = +1.88  -> agree

   AND THE HALF THAT CAN REFUTE D&W.  Uniform and bidisperse both have
   S = 0 EXACTLY and the same delta, so Eq. (4) gives them the SAME phi_RCP
   at every CV -- D&W's two parameters cannot tell them apart.  If the data
   separates them, the two-parameter closure is refuted as a complete
   description, whatever it gets right about lognormal-vs-uniform.

5. THE MATCHED-BINARY PAIR -- D&W's prediction against the headline number
==============================================================================
   The manuscript's pair: size ratio 3, number-CV 0.500, two compositions.
   From geom_psd_functional_class: q_large = 1/2 gives S = 0 and q_large =
   1/10 gives S = +8/3.  delta = 0.5 for both.  So D&W predicts a gap made
   entirely by the skewness term:
     A (n_small = 0.500, X_s = 1/28): delta = 0.500000, S = +0.000000, phi_DW = 0.666900
     B (n_small = 0.900, X_s = 0.25): delta = 0.500000, S = +2.666667, phi_DW = 0.724033

   D&W predicted gap = c2 * S_B * delta^2 = 0.0857 * 2.666667 * 0.25 = +0.057133
   Manuscript measured gap (paper/numbers.tex \pairDPhi, \pairDPhiSe,
   at p_hat = 1e-3, mu_p = 0.3, N = 1500):  +0.0635 +- 0.0032
   difference = +0.00637  = +1.99 se   -> AGREE at 2 dof
   The project's own two-exponent filling closure predicts +0.0604
   (paper/numbers.tex \pairFillingPred), which is +0.00327 from D&W.

   WHAT THIS DOES AND DOES NOT SHOW.
   (a) It is a genuine EXTERNAL prediction: D&W's three constants were fitted
       in 2013 to 81 frictionless packings of other distributions, with no
       knowledge of this pair, and the pair is the manuscript's headline.
   (b) S = +2.667 is OUTSIDE D&W's posted range (max |S| = 2.50) by 6.7%,
       and that end of their range is carried by BINARY packings only --
       which is, at least, the same kind of distribution as this pair.
   (c) It is a comparison of INCREMENTS, not levels: D&W's absolute numbers
       (0.6669 and 0.7240) are frictionless and the measurement is at
       mu_p = 0.3 (0.6042 and 0.6677).  The comparison is only licensed by
       item A's additive separability, and inherits its ~6% residual.
   (d) One agreement is not a validation.  The refuting test is section 4.
