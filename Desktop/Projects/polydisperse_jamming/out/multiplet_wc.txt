=== 1. THE COVARIANCE THAT COLLAPSES THREE PARAMETERS INTO ONE ===
   eta = ETA_S (1 - PHI/phiJ)^-2,  phiJ = PHI0 - (PHI0-PHIM) fhat.
   Under (PHI, PHI0, PHIM) -> c (PHI, PHI0, PHIM), PHI/phiJ is unchanged at
   every fhat, and fhat's own dynamics read sigma/SIGMA_STAR, not phi.
      fhat = 0.0:  phi/phiJ = 0.8387096774   rescaled by c = 1.37: 0.8387096774
      fhat = 0.5:  phi/phiJ = 0.9285714286   rescaled by c = 1.37: 0.9285714286
      fhat = 1.0:  phi/phiJ = 1.0400000000   rescaled by c = 1.37: 1.0400000000
   -> the covariance is EXACT, so only the RATIO Lambda/G can move the solver.

   ⚠ SCOPE, added after referee pass 2. The covariance was verified against the
   solver source: `eps = 1 - PHI/phiJ` is scale-invariant, and the hard clip,
   `EPS_SOFT` and `MP_EXPO` all act on `eps`, so none of them breaks it. BUT
   the claim holds only at DIL_COEFF = 0. The Reynolds-dilatancy / Darcy term
   is built from a `perm_factor(PHI)` that uses a FIXED `PHI_REF = 0.49`, which
   is NOT one of the three rescaled parameters, so that term is NOT covariant.
   DIL_COEFF defaults to 0 and is not in WC_DEFAULT, so no number here is
   affected -- but a DNS run with dilatancy on is outside this mapping.

=== 4. SIGMA_STAR IS NOT MAPPED, AND WHY ===
   The onset stress is a force divided by an area, and WHICH area is a
   convention this module is not entitled to choose:
      (a) the MONOMER convention -- the repulsive force is a surface
          interaction between two monomer surfaces at contact, so the area is
          d_1^2 and SIGMA_STAR does NOT move with aggregation;
      (b) the AGGREGATE convention -- the stress is transmitted across the
          multiplet's cross-section, so the area is d_k^2 and SIGMA_STAR falls
          like <d^2>^-1, i.e. by a factor k^(2 gamma/3).
   These differ by orders of magnitude and they predict opposite trends.
   `SIZE_THRESHOLD_2026-09-08.md` and `derivations/onset_size_degeneracy_2026-
   09-19.md` already own this question; the second one's verdict is a NEGATIVE
   (a size ladder cannot separate the two grain-scale stresses). Choosing here
   would be picking a convention and calling the consequence a result -- which
   this repository has been caught doing before. It is left OPEN and flagged.

   ⚠ CONSEQUENCE FOR THE DNS: a solver run built from section 3 varies PHI,
   PHI0 and PHIM at FIXED SIGMA_STAR. That is convention (a). It must be
   labelled as such in the run's metadata, not presented as the mapping.
