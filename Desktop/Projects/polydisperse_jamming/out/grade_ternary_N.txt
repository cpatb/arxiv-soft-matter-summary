=== NA3 -- the correlation that raised the alarm, recomputed POOLED ===
   If the residual is set by n_L, doubling n_L must move it and the pooled
   correlation survives. If it is set by composition, the N = 3000 points sit
   at the SAME residual with DOUBLE the n_L, which destroys the correlation.
   `d_max/L` is read from the SOLVER's own record, not recomputed: it is the
   second face of the same confound (spearman +1.0000 with the residual at
   N = 1500) and doubling N multiplies it by 2^(-1/3) = 0.794.
   within N = 1500: spearman(res, n_L) = -1.0000 (p 0.0000, n 6)
   within N = 3000: spearman(res, n_L) = -1.0000 (p 0.0000, n 6)
   POOLED over 12 points:      = -0.3077 (p 0.3306)
   POOLED spearman(res, d_max/L) over 12 points = +0.3077 (p 0.3306); d_max/L spans 0.1586-0.2256 across both N
   -> NA3: n_L is EXCLUDED as the explanation (bar |rho| 0.6)
   NOTE the within-block correlation is expected to stay strong in BOTH blocks
   whatever the answer, because n_L and y_S are collinear at fixed N by
   construction. Only the POOLED number can separate them, which is the whole
   reason the second N was run.
