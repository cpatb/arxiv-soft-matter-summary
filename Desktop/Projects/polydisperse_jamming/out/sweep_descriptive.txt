4. THE SHAPE-OVER-CV CONTRAST, on every channel, at p_hat = 1e-3.
   For each observable: the CV 0 -> 0.5 change WITHIN a family, and the spread of
   that change ACROSS families. A ratio > 1 in the last column means the shape of
   the size distribution moves the observable more than a fourfold change in CV
   does within any one family.

   Changes are PAIRED PER SEED, never a difference of two means: the two ends
   share the seed, so the paired form cancels the shared draw exactly rather than
   statistically (lessons.md 2026-08-30). Each change is printed with its own se,
   and a ratio whose SMALLEST change is not significantly non-zero is reported
   UNDETERMINED -- a relative measure whose denominator is shrinking measures the
   shrinkage.

   ⚠ THE GUARD IS t(df = n-1), NOT 2*se (referee, 2026-09-18). Every change here
   comes from 3 seeds, so its se carries 2 dof and the two-sided 95 % critical
   value is t = 4.303, not 2. P(|T| > 2, df = 2) = 0.184, so a flat
   2*se bar is an 18 % test. The first version of this script used 2*se and it
   admitted exactly the change that carries the headline.

   ⚠ THE UNDETERMINED FLAG AND THIS TEST ASK DIFFERENT QUESTIONS. The flag asks
   whether the SMALLEST family's change is non-zero; the ordering claim needs
   whether the family changes DIFFER FROM EACH OTHER. A ratio is called RESOLVED
   below only if it passes BOTH -- which is strictly stricter than the guard it
   replaces, and it is what demotes Z_nr, whose denominator clears its own
   threshold by 1.17x while its heterogeneity F does not reach 5 %.

   A SIGNIFICANT OMNIBUS F SAYS SOME PAIR DIFFERS, NOT THAT THE QUOTED PAIR DOES.
   The ratio is max/min, so the contrast actually being quoted is that ONE pair,
   and it gets its own Welch t (referee, third pass). Not live on today's data --
   but a channel with three clustered means and one outlier could pass the
   omnibus and fail this.
   ⚠ AND THE PAIR IS SELECTED FROM THE DATA, so a nominal two-sample t_crit
   UNDER-corrects -- the same defect as using 2*se on 3 seeds, one level up. The
   threshold is therefore CALIBRATED by Monte Carlo: simulate each channel's own
   (mean, se, n) under the null that all three families share the pooled value,
   apply the SAME argmax/argmin selection rule, and take the 95th percentile of

   READ THIS WITH THE FOLLOWING RESTRICTIONS, none of which is optional:
   - bidisperse is 50:50 BY NUMBER, so its fines carry 0.500 -> 0.036 of the
     VOLUME across this CV ladder. It is a PATH through the (ratio, composition)
     plane and not a representative 'bidisperse family'; the 2026-09-13 block
     found matched binaries 0.0635 apart in phi where every PSD descriptor
     predicts 0.
   - a ratio across families is a spread, not a pairwise separation. It says the
     three families differ; it does not say any two of them are distinguishable
     at a given CV.
   - Z, the rattler fraction and the force moments are read AT a pressure and
     move with the rung; phi_J alone is extrapolated to p_hat -> 0.
