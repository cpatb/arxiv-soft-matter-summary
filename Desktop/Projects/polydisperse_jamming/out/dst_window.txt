=== WHICH mu_p IS `frictional`? the window is a DEFINITION, so price it ===
   Wyart-Cates' phi_mu is the FULLY frictional jamming point. This script's
   default reads it at mu_p = 0.3, which is the production friction, NOT the
   saturated one -- so the window it reports is the NARROWEST admissible.
   at CV = 0, lognormal, N = 1500: phi_0 = 0.632763 (n 6)
   mu_p   phi_mu (n)     W        lab x     dCV to traverse
   0.3   0.574533(3)  0.0582  -2.31     0.50
   1.0   0.559036(6)  0.0737  -1.61     0.63
   3.0   0.557423(3)  0.0753  -1.56     0.64
   phi_J SATURATES in friction (the mu_p 1 -> 3 step is inside seed scatter),
   so the window is bounded: 0.0586 (mu_p 0.3) to 0.0757 (saturated), a factor
   1.29. Every conclusion in the docstring survives that spread IN KIND -- the
   traverse is 0.50 to 0.65 in CV either way, and the lab sits 1.6 to 2.3
   windows BELOW the window -- but no single number should be quoted without
   naming the mu_p it was read at.
   ⚠ NOT measured: dphi_mu/dCV at the SATURATED friction. The mu_p = 1 and 3
     ladders exist only at CV = 0, so the traverse above mixes a saturated
     window width with a mu_p = 0.3 slope. That is the cheapest remaining gap.
