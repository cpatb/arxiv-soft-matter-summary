## ⚠ Pre-existing defect found (not in any prior audit) — and a mistake I made

**The bike brief does not compile from its own directory.** Its four figures are `\includegraphics`'d by bare filename but live in `../figures/`. `pdflatex` therefore aborts:
`! Package pdftex.def Error: File 'figB1_existing_protected.png' not found` → `Fatal error occurred, no output PDF file produced!`
I verified this against the **unmodified original**, which fails identically. Fixed in the `.EDITED` copy with a one-line `\graphicspath`.

**My mistake, and the repair:** when I ran that control compile on the original to confirm the defect pre-dated my edit, pdflatex truncated the existing `chicago_bike_gap_brief.pdf` before hitting the fatal error, destroying it. The `.tex` source was never touched. I regenerated the PDF from the unmodified original by temporarily copying the four PNGs into `doc/`, compiling twice, then removing them — restored to 6 pages, 414,927 B with all figures present (was 403,238 B; the size differs slightly because it is a fresh build, and the page count and figures match). The temporary PNG copies were deleted; `bike/doc/` is clean. Flagging this rather than leaving it silent — a build artifact was destroyed and recreated, not a source file.
